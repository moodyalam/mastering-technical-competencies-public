| File | What it is |

| [img/](img/) | The diagrams: [the pipeline](img/pipeline.svg), [the branch loop](img/branch-loop.svg) and [the gate](img/gate.svg) |

**Accessibility:** every slide has a unique title; text and code colours meet
the WCAG 2.2 AA contrast ratio; nothing relies on colour alone (a pass is a
circle with a tick and the word *pass*, a fail is an octagon with a cross and
the word *fail*); the diagrams are SVG with a title and a description for
screen readers; and the smallest text is 24 px on a 1280 px-wide slide. If any
part doesn't work for you, tell the lecturer and we'll provide another format.

# Lecture 4 Slides

**Lecture 4: The Monday After the 3 AM Page, Continued**

| File | What it is |
|---|---|
| [lecture-4.html](lecture-4.html) | The slides as a web page: the most accessible version. Open in a browser; it works with screen readers and browser zoom. Press `F` for full screen |
| [lecture-4.pdf](lecture-4.pdf) | The slides as a PDF, with a bookmark for every slide |
| [lecture-4.md](lecture-4.md) | The source: a [Marp](https://marp.app/) Markdown file. Plain text, so it also works with a screen reader, text-to-speech or your own font and colours. Open it in VS Code with the *Marp for VS Code* extension to see the slides beside the text |

**Accessibility:** every slide has a unique title; text and code colours meet
the WCAG 2.2 AA contrast ratio; nothing relies on colour alone; and the
smallest text is 24 px on a 1280 px-wide slide. If any part doesn't work for
you, tell the lecturer and we'll provide another format.
